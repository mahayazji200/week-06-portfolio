المهمة 1: معرض أعمال متحرك

ابنِ قسماً لمعرض أعمال (Portfolio) باستخدام التحريك (Animation) والانتقالات (Transitions) والتحويلات (Transform) والخصائص المخصصة (CSS Variables) في CSS. اكتب التنسيقات في الملف portfolio.css.

TODO 1: عرّف متغيرات CSS داخل :root

أنشئ متغيرات للألوان والمسافات وتدوير الزوايا (border-radius) وسرعات الانتقال.

المتغيرات: --primary: #4caf50، --bg-dark: #0f0f1a، --bg-card: #1a1a2e، --text: #e0e0e0، --radius: 12px، --transition: all 0.3s ease

TODO 2: شريط تنقل مع تأثيرات الانتقال

نسّق روابط شريط التنقل بحيث يتغير لونها بسلاسة عند تمرير الفأرة (Hover). أضف تأثير خط سفلي باستخدام العنصر الوهمي ::after مع transform: scaleX(0) ليتمدد إلى scaleX(1) عند التمرير.

تلميح: استخدم .nav-link::after { content: ""; display: block; height: 2px; background: var(--primary); transform: scaleX(0); transition: transform 0.3s; } و .nav-link:hover::after { transform: scaleX(1); }

TODO 3: نص القسم الرئيسي مع حركة ظهور تدريجي

أنشئ حركة @keyframes fadeInUp وطبّقها على العنوان الرئيسي والعنوان الفرعي مع تأخيرات متتالية.

تلميح: @keyframes fadeInUp { from { opacity: 0; transform: translateY(30px); } to { opacity: 1; transform: translateY(0); } }. استخدم animation-delay لجعل العناصر تظهر واحداً تلو الآخر.

TODO 4: بطاقات المهارات مع تكبير عند التمرير

يجب أن تكبر كل بطاقة مهارة قليلاً عند التمرير باستخدام transform: scale(1.05) مع انتقال سلس.

تلميح: ضع transition: var(--transition) على البطاقة، ثم transform: scale(1.05) وظلاً أخضر box-shadow عند التمرير.

TODO 5: بطاقات المشاريع مع طبقة فوق الصورة

أنشئ طبقة علوية (Overlay) على بطاقات المشاريع تظهر تدريجياً عند التمرير. يجب أن تعرض الطبقة اسم المشروع وزر "عرض".

تلميح: .project-overlay { opacity: 0; transition: opacity 0.4s; } و .project-card:hover .project-overlay { opacity: 1; }

TODO 6: حركات تظهر مع التمرير (باستخدام CSS فقط)

استخدم الخاصية animation مع animation-timeline: view()، أو حركات @keyframes بسيطة تعمل عند تحميل الصفحة لتعطي تأثيراً يشبه الظهور مع التمرير.

تلميح: طبّق حركة fadeInUp على كل قسم مع زيادة التأخير تدريجياً: .skills-section { animation: fadeInUp 0.8s ease-out 0.2s both; }
